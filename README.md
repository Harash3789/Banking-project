Banking Dashboard – Data Analytics Project

📊 Project Overview

This project is a Banking Dashboard – Data Analytics Project focused on analyzing banking data to understand customer information, loan performance, deposit trends, and account activities.

The project uses Excel, SQL, Python, and Power BI to transform banking data into meaningful insights and present them through an interactive dashboard.

🎯 Objectives

- Analyze the total number of clients and customer-related information.
- Examine loan performance, including bank loans and business lending.
- Analyze deposits, savings accounts, and checking account activities.
- Understand credit-card amounts, banking fees, and foreign currency transactions.
- Develop an interactive Power BI dashboard with KPIs, analysis pages, and drill-through features.

🛠️ Technologies Used

- Microsoft Power BI – Dashboard and data visualization
- Power Query – Data cleaning and transformation
- DAX – KPI and calculated measures
- SQL – Data analysis and querying
- Python – Data analysis and processing
- Excel – Data preparation and source data handling

🔄 Project Workflow

1. Identify business questions and required banking measures.
2. Connect relevant source tables in Power BI.
3. Review column names, data types, missing values, and duplicate records.
4. Transform the source data using Power Query where required.
5. Create relationships between relevant tables in the data model.
6. Define required KPIs using DAX.
7. Arrange visuals into different dashboard pages.
8. Configure drill-through fields, navigation, and filtering.
9. Validate KPIs against the underlying data.

📌 Project Outcome

The final outcome is an interactive Banking Dashboard that provides a structured view of banking information and helps users understand different banking performance indicators.

The project demonstrates the use of data preparation, data modelling, DAX measures, KPIs, and interactive visualization for banking analytics.
